# Banco de Ideias

Aplicação web em React (Vite) para registrar ideias de projeto. Permite cadastrar uma ideia, editar o título, marcá-la como pendente ou executada e excluí-la. A lista é carregada de uma API pública, e a tela mostra os estados de carregando, erro e lista vazia.

## Como instalar e rodar

```bash
npm install
npm run dev
```

Depois, abra no navegador o endereço mostrado no terminal (por padrão, `http://localhost:5173`).

## API utilizada

`https://jsonplaceholder.typicode.com/todos`
